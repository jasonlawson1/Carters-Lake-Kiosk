# Team-P06-01-Project
# Interactive Game Hub and Engagement Analysis
### Carters Lake Visitor Center

Capstone project developed for the U.S. Army Corps of Engineers – Carters Lake Visitor Center.

## Project Overview

The Interactive Game Hub and Engagement Analysis project is a touchscreen-based
kiosk platform designed to centralize educational games available to visitors at
the Carters Lake Visitor Center.

The system is intended to provide visitors with a simple way to browse and launch
educational games, record and view scores, and interact with the kiosk without
requiring a physical keyboard or mouse.

The platform will also provide authorized ranger/administrator functionality for
game management, score and leaderboard management, and visitor-engagement
analytics.

The system is designed to operate offline using local data persistence and to
support the addition of educational games in the future.

## Core Project Areas

- Touchscreen kiosk interface
- Unified game launcher
- Digital touchscreen keyboard
- Scorekeeping and leaderboards
- Visitor-engagement analytics
- Ranger/administrator tools
- Local/offline data persistence
- Support for future game integration

## Development Workflow

Development will use Git and GitHub for version control and collaboration.

General workflow:

1. Select or be assigned a project task.
2. Create an appropriately named feature/fix branch.
3. Implement and test the change.
4. Commit changes with descriptive commit messages.
5. Push the branch to GitHub.
6. Open a pull request.
7. Have another team member review the change.
8. Resolve applicable review comments.
9. Merge approved work into the main branch.

The `main` branch should represent stable, integrated project work.
